# FedKnn for overlapping

## Usage

### install library

```bash
cd src/
pip install -r requirements.txt
```

### How to Use

**lanuch client:**

```python
python lanuch_clients.py dataset={dataset_name}`
```

**lanuch server:**

```python
python lanuch_server.py server={overlapping_method}
```
